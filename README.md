# ITINERA Dashboard v4

Premium travel-dashboard redesign inspired by the supplied Figma travel dashboard reference.

## Features
- Dark-first dashboard architecture with clean light mode
- Full-page rain/season atmosphere with ON/OFF control
- 36 Indian states/UTs and 144 starter destinations
- Global search
- Month, trip length, vibe, budget and state filters
- Destination cards and detailed destination modal
- Destination-specific YouTube search
- 1–7 day roadmap with icons
- Save trips with browser localStorage
- India Atlas
- Travel Films page
- Calendar, trips rail and quick dashboard views
- Responsive mobile sidebar
- Readable high-contrast light/dark variables

## GitHub Pages
Upload all five files to repository root:
`index.html`, `style.css`, `script.js`, `data.js`, `README.md`

Then:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.
