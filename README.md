# ITINERA — India, Your Way

A premium, season-smart India travel planner built with pure HTML, CSS and Vanilla JavaScript.

## GitHub Pages
1. Upload every file in this folder to the root of a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
4. Save. No build command, Node.js or server is required.

## Files
- `index.html` — application structure
- `style.css` — responsive premium visual system
- `data.js` — destination/state data
- `script.js` — navigation, seasonal effects, filters, planner and local saving
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## Notes
Destination photography uses remote image URLs. You need an internet connection for remote images, fonts and YouTube links to load.
